# Game Catalog

Catálogo de videojuegos en Angular que consulta una API REST creada con JSON Server 0.17.4. `GameService` realiza las peticiones GET (colección, por id, filtros, búsqueda, rango de precios y paginación con `X-Total-Count`) y `AppComponent` gestiona la interfaz.

## Ejecución

    npm install
    npm run api      # terminal 1: JSON Server en http://localhost:3000
    npx ng serve     # terminal 2: Angular en http://localhost:4200
